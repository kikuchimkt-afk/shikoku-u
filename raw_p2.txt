四国大学 英語 模擬試験問題（大問2：整序英作文 50問）
本問題集は、四国大学の一般選抜における「大問2：整序英作文」の頻出パターンを網羅したオリジナル問題50選です。語句を並べ替えて意味の通る英文を完成させてください。
Ⅱ. 次の各文がそれぞれの日本文と同じ意味になるように、(     )内の語句を並べ替えて、正しい順序を答えよ。
(1) 私は新しい家へ引っ越すのを楽しみにしています。
I am ( forward / looking / moving / to ) to a new house.
(2) あまりにも寒くて、私たちは外へ出られませんでした。
It was ( cold / for / too / us / go / to ) to go out.
(3) 彼は試験に合格するために一生懸命勉強した。
He studied hard ( as / order / in / to / pass / so ) the exam.
(4) 忘れずにその手紙を投函してください。
Please ( to / mail / remember / don't / forget ) the letter.
(5) その知らせを聞いて、彼女は泣きだした。
Hearing the news, ( began / she / to / cry ).
(6) 彼女は以前よりもさらに美しくなった。
She has become ( before / more / even / beautiful / than ).
(7) ここから駅まで歩いてどのくらいかかりますか。
How long ( take / does / to / it / walk ) from here to the station?
(8) 彼は親切にも私を駅まで送ってくれた。
He was ( me / enough / to / kind / drive ) to the station.
(9) 私はその問題をどう解決すればいいかわからない。
I don't know ( problem / the / how / solve / to ).
(10) 彼は私に嘘をつかないようにと約束した。
He promised ( a lie / tell / to / not / me ).
(11) 彼女は医者になることを決心した。

(12) 雨が降れば、試合は中止されるだろう。
If it rains, ( canceled / be / the / game / will ).
(13) 彼は有名な作家だと言われている。
( that / said / is / It ) he is a famous writer.
(14) 私は彼がその会合に来るかどうか確信がない。
I'm not sure ( will / whether / come / he ) to the meeting.
(15) もっと一生懸命勉強していたら、合格できたのに。

(16) 君が今日ここに来てくれるとは思わなかったよ。
I didn't ( would / here / expect / you / to / come ) today.
(17) 早起きは健康によい。
( up / early / Getting ) is good for your health.
(18) 彼は私の3倍の本を持っている。
He has ( as / books / as / three / many / times ) as I have.
(19) これは私が今まで見た中で最も美しい写真です。
This is ( picture / most / I've / beautiful / the ) ever seen.
(20) ドアを閉めたままにしておいてください。
Please ( closed / door / the / leave ).
(21) 彼は私に何があったかを教えてくれなかった。
He didn't ( tell / happened / what / me / had ).
(22) 君はただ座って待っているだけでいい。
All you ( do / is / sit / have / to ) and wait.
(23) 私は昨日、自転車を修理してもらった。
I ( my / had / repaired / bike ) yesterday.
(24) 彼はその知らせを聞いて驚いているようだ。
He ( be / surprised / seems / to ) to hear the news.
(25) 富士山は日本で最も高い山です。
Mt. Fuji is ( mountain / the / highest ) in Japan.
(26) 彼は有名な俳優として知られている。
He is ( known / as ) a famous actor.
(27) 彼女はピアノを弾くのが上手です。
She is ( at / playing / good ) the piano.
(28) 私は以前そこに住んでいたことがある。
I ( to / used / live ) there.
(29) 外出するよりは家にいたい。
I ( would / rather / stay / home ) than go out.
(30) たとえ雨が降っても、私は行くつもりだ。
( Even / it / if ) rains, I will go.
(31) 彼は健康のためにタバコを吸うのをやめた。
He ( up / smoking / gave ) for his health.
(32) 窓を開けてもよろしいでしょうか。
Would you ( opening / mind ) the window?
(33) 私は彼に駅への道を尋ねた。
I ( him / asked ) the way to the station.
(34) 彼女はとても親切なので、みんなに好かれている。
She is ( kind / that / so ) everyone likes her.
(35) 彼は私にそれをするように言った。
He ( me / do / to / told ) it.
(36) 彼女がここへ来るかどうかはわからない。
( Whether ) she will come here is unknown.
(37) 私は昨夜1時間英語を勉強した。

(38) 彼は医者ではない。教師でもない。

(43) 彼女は金持ちであるかのように振る舞う。

(44) 彼は自分の成功を誇りに思っている。
He is ( of / proud ) his success.
(45) 私は彼に泳ぎ方を教えた。
I ( him / showed ) how to swim.
(46) 彼女は私よりも背が高い。
She is ( than / taller ) me.
(47) 彼がそこへ行ったのは事実だ。

(48) 私は英語で手紙を書くのが難しいとわかった。
I found ( it / difficult ) to write a letter in English.
(49) 彼は嘘をつくような人ではない。
He is ( the / last ) man to tell a lie.
(50) 駅に着くとすぐに雨が降り出した。
( had / I / the station / reached / Scarcely ) when it began to rain.
解答とポイント
(1) 
looking forward to moving
 (look forward to ~ing: 〜を楽しみに待つ)
(2) 
too cold for us to go
 (too ~ to ...: 〜すぎて...できない)
(3) 
in order to pass
 (in order to do: 〜するために) ※so as toも同様
(4) 
remember to mail
 (remember to do: 忘れずに〜する)
(5) 
she began to cry
 (began to do: 〜し始めた)
(6) 
even more beautiful than
 (even: 比較級の強調)
(7) 
does it take to walk
 (It takes 時間 to do の疑問文)
(8) 
kind enough to drive me
 (形容詞 + enough to do: 〜するほど十分に...)
(9)

 (疑 + to do: 〜のしかた)
(10) 
not to tell me a lie
 (不定詞の否定 not to の位置に注意)
(11) 
made up her mind to become
 (make up one's mind to do: 〜する決心をする)
(12) 
the game will be canceled
 (助動詞 + 受動態 be p.p.)
(13) 
It is said that
 (〜と言われている：伝聞の形式主語構文)
(14) 
whether he will come
 (whether S V: 〜かどうか)
(15) 
could have passed
 (仮定法過去完了の帰結節: could have p.p.)
(16)

 (expect A to do: Aが〜すると予期する)
(17) 
Getting up early
 (動名詞の主語：〜すること)
(18)

 (倍数 + as many 名詞 as)
(19)

 (関係代名詞の省略)
(20)

(21)

 (第4文型 tell 人 物 / 間接疑問文)

 (All S have to do is do: Sはただ〜しさえすればよい)

 (Would you mind ~ing?: 〜していただけませんか)
